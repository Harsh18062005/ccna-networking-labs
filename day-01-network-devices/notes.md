# Day 01 – Network Devices

## Objective

Understand the basic devices used in computer networks and their functions.

## Topics Covered

### 1. Router

* Connects different networks together.
* Makes forwarding decisions using IP addresses and routing tables.
* Operates mainly at Layer 3 (Network Layer).

### 2. Switch

* Connects devices within the same Local Area Network (LAN).
* Uses MAC addresses to forward frames efficiently.
* Operates at Layer 2 (Data Link Layer).

### 3. Hub

* Sends incoming data to every connected device.
* Does not learn MAC addresses.
* Causes more unnecessary traffic than a switch.

### 4. Firewall

* Monitors and filters incoming and outgoing network traffic.
* Protects networks from unauthorized access.
* Can allow or block traffic based on security rules.

### 5. End Devices

Examples:

* PC
* Laptop
* Smartphone
* Server
* Printer

These devices generate or receive network data.

## Key Learnings

* Routers connect different networks using IP addresses.
* Switches connect devices inside a LAN using MAC addresses.
* Hubs broadcast data to all connected devices.
* Firewalls improve network security by filtering traffic.
* End devices are the source and destination of communication.

## Quick Comparison

| Device   | Main Function             | OSI Layer       |
| -------- | ------------------------- | --------------- |
| Router   | Connects networks         | Layer 3         |
| Switch   | Connects LAN devices      | Layer 2         |
| Hub      | Broadcasts to all devices | Layer 1         |
| Firewall | Filters traffic           | Multiple Layers |
